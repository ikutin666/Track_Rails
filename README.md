## Принцип работы с запросами

Для типовых сценариев языковая модель не создаёт запрос с нуля. Она определяет
намерение пользователя, выбирает проверенный шаблон из каталога и заполняет только
разрешённые параметры. В каталоге хранятся шаблоны SQL для аналитического хранилища
и шаблоны обращений к внешним сервисам. Свободная генерация используется только как
резервный вариант и всегда проходит проверку безопасности.

Запросы к языковым моделям проходят через отдельный балансировщик нагрузки. Он
распределяет обращения между основными, резервными и локальными моделями с учётом
доступности, очереди, времени ответа, лимитов и стоимости.
